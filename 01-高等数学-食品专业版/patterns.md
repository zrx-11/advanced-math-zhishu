# 模式与框架库

## 框架：极限计算的五级漏斗

按顺序过，前一级能出结果就停。

1. **代入**：把 $x$ 的值直接代进去。不是未定式就有答案。
2. **化简**：约公因式、通分、有理化、分子分母同除最高次幂。
3. **等价替换**：只对乘除因子替换。$x\to0$ 时 $\sin x\sim x$、$1-\cos x\sim x^2/2$、$\ln(1+x)\sim x$。
4. **两个重要极限或洛必达**：结构像 $\frac{\sin\Box}{\Box}$ 用第一个；像 $(1+\Box)^{1/\Box}$ 用第二个；$\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 用洛必达。
5. **泰勒展开**：前四级都卡住，或需要保留高阶项时，展开到同阶。

## 框架：积分的三层策略

1. **查表**：能直接对上基本积分表就写答案，别忘了 $+C$。
2. **换元**：
   - 看见"函数 + 它的导数"配对，用第一类（凑微分）。
   - 看见根式 $\sqrt{ax+b}$ 或 $\sqrt{a^2-x^2}$，用第二类。
3. **分部**：两类不同函数相乘，按 LIATE 选 $u$。多项式配指数/三角，多项式当 $u$；多项式配对数/反三角，对数/反三角当 $u$。
4. **兜底变形**：拆项、配方、分子分母同除、倒代换。

## 框架：微分方程识别树

- 一阶：
  - 能写成 $f(x)g(y)$ → 可分离变量。
  - 能写成 $\varphi(y/x)$ → 令 $u=y/x$。
  - 形如 $y'+P(x)y=Q(x)$ → 积分因子。
- 二阶：
  - 缺 $y$ 或缺 $x$ → 降阶（令 $p=y'$）。
  - 常系数齐次 → 特征方程。
  - 常系数非齐次 → 齐次通解 + 待定特解。
- 应用题：先写"变化率 = 什么"，再判断方程类型。

## 框架：最优化四步

1. 设变量，写目标函数。
2. 用约束消元，化成一元（或多元）。
3. 求导找驻点，或用拉格朗日乘数法。
4. 判断最大/最小：二阶导、实际意义、端点比较。

## 框架：二重积分定限

1. 画区域。
2. 判断 X 型还是 Y 型，或圆域转极坐标。
3. 写内层上下限（可含外层变量），再写外层常数限。
4. 内层积不出来，换序。

## 框架：级数判别

1. 通项不趋于 0 → 发散，结束。
2. 正项 → 比值或根值；$L=1$ 时换比较或积分。
3. 交错 → 莱布尼茨；再看绝对值级数判断绝对/条件收敛。
4. 幂级数 → 先求 $R$，再单独查端点。

## 决策规则

- 看到 $\frac{0}{0}$：先因式分解，再等价替换，最后洛必达。
- 看到根号差：先有理化。
- 看到 $x^x$ 或幂指函数：先取对数。
- 看到"总量""累积""平均"：想积分。
- 看到"变化率与当前量成正比"：想指数解 $y=Ce^{kt}$。
- 看到"有上限的增长"：想逻辑斯蒂。
- 看到"固定周长/面积/体积，求最大/最小"：想拉格朗日或边界最优。
- 看到 $R^2$ 很高：先问模型假设是否成立，再看残差图。

## 反模式

- **硬用洛必达**：不是未定式也求导，答案必错。替代：先代值判断类型。
- **加减法里替换等价无穷小**：会丢高阶项。替代：通分后用泰勒展开到同阶。
- **积完忘 $+C$**：不定积分是一族函数。替代：每写完立即检查常数。
- **换元不换上下限**：定积分换元后仍用原限，结果必错。替代：换元的同时改写限。
- **极坐标漏 $r$**：面积元是 $r\,dr\,d\theta$。替代：写完面积元先检查量纲（长度²）。
- **把极值当最值**：极值只在邻域内比较。替代：闭区间题必须比端点。
- **把 $R^2$ 当模型正确性**：过拟合也能高。替代：看残差、看外推验证。
- **步长无限缩小**：浮点误差反噬。替代：中心差商取 $h\approx10^{-5}$，或直接换自适应算法。
