# 导数定义与瞬时变化率

- **难度**：进阶 | **涉及章节**：第 2 章、第 3 章

## 一句话定义

导数是平均变化率在自变量增量趋于 0 时的极限，几何上是切线斜率，物理上是瞬时变化率。

## 为什么重要

导数把"一段时间的平均"变成"某一刻的瞬时"，是描述变化快慢的统一工具。浓度下降多快、温度降多快、成本随产量涨多快，全靠它。后面所有最优化、曲线形状分析，都从导数出发。

## 详解

$$f'(x_0)=\lim_{\Delta x\to0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$$

三步算定义：写增量比、化简约分、取极限。以 $f(x)=\sqrt{x}$ 在 $x=4$ 为例：

$$\frac{\sqrt{4+h}-2}{h}=\frac{(4+h)-4}{h(\sqrt{4+h}+2)}=\frac{1}{\sqrt{4+h}+2}\to\frac{1}{4}$$

所以 $f'(4)=\frac{1}{4}$。

几何意义：切线斜率。切线方程 $y-f(x_0)=f'(x_0)(x-x_0)$。

可导与连续：可导必连续，连续不一定可导。$|x|$ 在 0 处连续，左右导数分别是 $-1$ 和 $1$，不可导。

高阶导数：$f''$ 是变化率的变化率。冷却曲线 $T'<0$ 表示降温，$T''>0$ 表示降温速度在减慢。

## 常见误解

- 别把导数和"平均变化率"混同——$f'(x_0)$ 是一个点的瞬时值，$\frac{f(b)-f(a)}{b-a}$ 是区间平均值。
- 别以为导数为 0 就一定取极值——$y=x^3$ 在 0 处导数为 0，函数仍单调递增。
