# 数值积分与数值微分

- **难度**：进阶 | **涉及章节**：第 10 章

## 一句话定义

解析方法算不出的导数和积分，用差商和求积公式近似：数值微分用中心差商，数值积分用梯形或辛普森公式。

## 为什么重要

食品检测里很多函数没有初等原函数，或只有离散的测量数据。这时只能数值计算。理解误差阶，才知道该取多小的步长、结果能信到几位。

## 详解

**数值微分**：

$$f'(x)\approx\frac{f(x+h)-f(x-h)}{2h}\quad(O(h^2))$$

向前差商误差 $O(h)$，中心差商 $O(h^2)$。$h$ 不能太小：$h\sim10^{-12}$ 时浮点相减会损失有效位，总误差反而上升。实际取 $10^{-5}$ 到 $10^{-6}$。

**数值积分**：

- 梯形公式：$\int_a^bf\approx\frac{h}{2}[f_0+2f_1+\cdots+2f_{n-1}+f_n]$，误差 $O(h^2)$。
- 辛普森公式：每两段用抛物线，误差 $O(h^4)$。

```python
from scipy.integrate import quad
Q, err = quad(lambda t: 1.8*np.exp(-0.015*t), 0, 30)
```

```matlab
Q = integral(@(t) 1.8*exp(-0.015*t), 0, 30);
```

**离散数据积分**：只有采样点时用 `trapz`（MATLAB）或 `np.trapz`（Python），本质是梯形法。

## 常见误解

- 别以为步长越小越好——浮点误差会反向放大。
- 别把离散数据的梯形积分当成精确值——它和真实积分差一个 $O(h^2)$ 的误差。
